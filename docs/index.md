# OmniPost

Write a post once, publish it to eleven networks, and see exactly what
landed. Open source (AGPL), self-hosted or hosted.

- **[Deploy](DEPLOY.md)**: run it on one VPS with Docker Compose and TLS.
- **[Platform apps](APP_REVIEW.md)**: get Meta, TikTok, YouTube, X and
  LinkedIn apps approved.
- **[Architecture](ARCHITECTURE.md)**: how the API, worker, scheduler and
  web app fit.
- **[API and automation](api.md)**: API tokens, webhooks, the MCP server.
- **[Contributing](CONTRIBUTING.md)** and the **[CLA](CLA.md)**.
- **[Roadmap](ROADMAP.md)**.

Source: [omnipost](https://github.com/suryaanshrai/omnipost) (deploy and
docs), [omnipost-api](https://github.com/suryaanshrai/omnipost-api),
[omnipost-ui](https://github.com/suryaanshrai/omnipost-ui).
