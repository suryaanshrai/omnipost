# Roadmap

What's planned, roughly in order. Ideas and votes: open an issue.

## Now

- Hosted OmniPost: one-click connect for Instagram, TikTok and YouTube
  (no developer apps of your own), managed media and backups, AI included.
- Platform app approvals for the hosted service (see APP_REVIEW.md).
- Prices for the hosted plans, tested on the landing page before billing
  goes live.

## Next

- A media library with folders and reuse across posts.
- Per-platform previews that look like the real post.
- Analytics over time: weekly trends and best times across all channels.
- n8n and Zapier nodes on top of the API and webhooks.
- More of the MCP server: media upload and calendar views from an AI
  assistant.

## Later

- Teams: invites, approvals and client review, presented for agencies.
- A connector guide so contributors can add networks.
- More networks (Pinterest, Reddit, Tumblr), chosen by demand.

## Done recently

- Analytics for X, LinkedIn, Facebook, Instagram, Threads and YouTube.
- Threads and first comments in the composer.
- Personal API tokens and an MCP server ("post from Claude").
- Link-in-bio page, evergreen reposting, RSS to drafts, UTM tagging,
  webhooks, a weekly digest email.
- Undo, bulk actions and status filters.
